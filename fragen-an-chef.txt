Fragen an den Chef – KI-Dashboard
=================================
Stand: 17.11.2026. Abhaken, was geklärt ist, und Antworten dahinter schreiben.


WICHTIGSTE FRAGEN
-----------------

[ ] 1. KI-Hotline: Was ist das für ein System?
       - Wie heißt der Anbieter / das Produkt? Oder hat jemand sie selbst gebaut?
       - NEU: Ist sie über die "VoiceBot"-Schnittstelle an san6 angebunden?
         (san6 hat dafür eigene Funktionen, siehe san6-pruefung.txt.) Wenn ja:
         An welche Orga-Gruppe gehen Rückrufwünsche und Anliegen?
       - Die Anzahl der Anrufe pro Tag gibt san6 nicht her. Gibt der Anbieter eine
         Statistik raus (Schnittstelle, Export, täglicher E-Mail-Bericht)?
       - Wer ist Ansprechpartner dafür?

[ ] 2. Firmenserver: Was läuft dort?
       - Steht der Server bei uns im Haus oder bei einem Dienstleister / in der Cloud?
       - Betriebssystem: Windows Server (welche Version, z. B. 2019/2022) oder Linux?
       - Läuft er rund um die Uhr, also auch um 5 Uhr morgens?
       - Läuft san6 auf demselben Server, oder kann der Server san6 im Netzwerk erreichen?
       - Darf ein zusätzliches Programm darauf laufen? Ist noch Platz frei
         (grob: 2 GB Arbeitsspeicher, 10 GB Festplatte reichen)?
       - Darf der Server ins Internet (zu Microsoft 365 und zur Claude-API)?
       - Darf dort Docker installiert werden? (Sonst geht es auch ohne, nur etwas mehr Aufwand.)
       - Wer betreut den Server (eigene IT oder externer Dienstleister), und wie bekomme ich
         Zugang zum Einrichten (Fernwartung, Benutzerkonto)?

KI / CLAUDE / DATENSCHUTZ
-------------------------

[ ] 12. Claude-API-Konto: Okay, dass wir unter console.anthropic.com ein Konto
        auf den Firmennamen anlegen und Guthaben im Voraus aufladen (z. B. 20 €)?
        - Mit welcher Firmenkreditkarte? Rechnungen gehen an die Firma (Buchhaltung).
        - Automatisches Nachladen bleibt AUS, zusätzlich wird ein Monatslimit gesetzt.
        - Das ist NICHT dasselbe wie ein Claude-Pro-Abo; das Abo funktioniert für Programme nicht.
[ ] 13. Monatliches Budget für die KI? (Schätzung bei einem Durchlauf am Morgen plus
        Fragen über den Tag: grob 10–50 € im Monat, wird nach dem Test genauer.)
[ ] 14. Datenschutz: Gibt es einen Datenschutzbeauftragten (intern oder extern)?
        Er sollte zustimmen. Laut Anthropic ist der Vertrag zur Auftragsverarbeitung (DPA)
        Teil der geschäftlichen Nutzungsbedingungen der API. Der Datenschutzbeauftragte
        sollte das prüfen und ob die Datenverarbeitung außerhalb der EU okay ist.
[ ] 15. Welche Daten dürfen an die KI? Vorschlag: Beträge, Kostenträger, Lieferanten,
        Betreff von Mails, Anzahl Anrufe – aber KEINE Patientennamen, Diagnosen oder
        Versichertennummern (die werden vorher durch Kürzel ersetzt).
